## IP 是不是真住宅，四步自己验

是双ISP原生住宅IP，但这件事不该只听商家说。这条线的IP来自越南西贡邮电（SPT）宽带运营商的小众地址段，属于住宅家宽属性，不是数据中心IP段，这是它和市面上多数越南VPS最实质的区别。

第三方测评给出的检测链条是这样：

1. **Ping0**：识别为家宽住宅IP，历史记录干净，没有明显滥用痕迹。
2. **IPinfo**：Company字段显示为ISP类型；ASN字段显示为非ISP。这是ISP名称里存在空格差异导致的识别偏差，实际属于同一运营商体系，不影响住宅属性判断。
3. **scamalytics**：欺诈值0，多个数据库识别为越南原生IP。这一条来自二手转述，测评原文没有给具体分值。
4. **路由与丢包**：放到下一节单独说。

如果你手上已经有一台机器，或者想验证别家宣传的“越南家宽IP”，按这四步走：

- 查ASN归属，看是运营商还是机房服务商
- 查ISP信息，看Company字段是不是宽带运营商
- 查IP类型识别结果，看被标成住宅、机房还是代理
- 查风控数据库记录，看欺诈分、VPN/代理标记、滥用历史

市面上不少所谓“越南家宽IP”实际是IDC IP或广播IP，只改了个地理位置标签，风控库里照样一片红。同一区域的TOTHOST TOT D11是个现成的对照：它的信任得分100、VPN 0、代理0、欺诈0、滥用0，看着很干净，但ASN滥用得分0.0301（High），Cloudflare流量占比显示真人21%、机器人78%。住宅属性只是第一关，不同风控库看的维度不一样，别把一项满分当成全部过关。

**能直连国内吗？**
能连，体验分运营商。移动最好，电信可接受，联通建议配香港或新加坡中转并开BBR。

**能跑越南TikTok吗？**
IP是越南本地运营商原生段，TikTok识别为越南区，第三方测评提到移动网络下直播表现稳定。账号能不能起来还取决于内容、手机号、操作节奏，IP只是过了第一道识别。

48小时内不满意全额退；超过48小时按使用周期折算，不是全额。年付中途退出同样按剩余月数折算。

**优惠码在哪填、有没有？**
结算页有优惠码输入框，填进去点验证，生效后总价会变。第三方测评页面流传过9折码，这些码没有在官方页面核验到当前有效性，能不能用以下单页验证结果为准，别为了几十块钱去赌来源不明的码。

**5个IPv6要另外买吗？**
不用，每台默认赠送5个原生越南IPv6。

**机房到底在河内还是胡志明市？**
官方产品和较新的横评都写胡志明市（原西贡），部分早期测评写河内。以胡志明市为准，介意的话下单前找客服确认一次。
